# AI Chat Bot - Виртуальная Подруга 💕

## Описание проекта
Чат-бот с ИИ-девушкой на базе ChatGPT для оказания эмоциональной поддержки одиноким мужчинам. Монетизация через систему подписок.

## ✅ Реализованные функции
- **Регистрация и авторизация пользователей** с JWT токенами
- **Чат с ИИ-девушкой "Анна"** через OpenAI API
- **Система подписок** с ограничениями по количеству сообщений
- **База данных** для хранения пользователей, чатов и сообщений
- **Красивый адаптивный интерфейс** с анимациями
- **Ограничения для бесплатных пользователей** (5 сообщений/день)

## 🚀 Функциональные URI

### Основные страницы
- **GET /** - Главная страница с формой входа/регистрации и чатом

### API эндпоинты
- **POST /api/register** - Регистрация нового пользователя
  - Параметры: `email`, `username`, `password`, `full_name`
- **POST /api/login** - Вход в систему
  - Параметры: `email`, `password`
- **GET /api/profile** - Получение профиля пользователя (требует авторизации)
- **POST /api/chats** - Создание нового чата (требует авторизации)
  - Параметры: `title`, `ai_personality`
- **GET /api/chats** - Список чатов пользователя (требует авторизации)
- **GET /api/chats/:chatId/messages** - Сообщения конкретного чата (требует авторизации)
- **POST /api/chats/:chatId/messages** - Отправка сообщения в чат (требует авторизации)
  - Параметры: `content`
- **GET /api/subscription-plans** - Список доступных планов подписки

## 🗄️ Архитектура данных

### Модели данных
- **users** - Пользователи системы
- **subscription_plans** - Планы подписки
- **payments** - История платежей  
- **chat_sessions** - Чаты пользователей
- **messages** - Сообщения в чатах
- **usage_stats** - Статистика использования

### Хранилище
- **Cloudflare D1** - Основная база данных SQLite
- **Локальная разработка** - `.wrangler/state/v3/d1` (автоматически)

### Схема данных
```sql
users (id, email, username, password_hash, subscription_type, messages_today)
chat_sessions (id, user_id, title, ai_personality, ai_character_settings)
messages (id, session_id, user_id, role, content, created_at)
subscription_plans (id, name, price, messages_per_day, features)
```
